En esta sección se comentarán conceptos relevantes a tener en cuenta a la hora de trabajar con redes neuronales artificiales. 
Entre ellos, los tipos mas comunes de redes, optimización y descenso de gradiente, funciones de pérdida, métricas de evaluación, entre otros. Estos conceptos son fundamentales para entender cómo funcionan las redes neuronales y cómo se pueden entrenar de manera efectiva para resolver problemas específicos.
