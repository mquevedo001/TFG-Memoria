Este Trabajo de Fin de Grado consiste en un acercamiento al problema de separación de fuentes en una obra musical que persigue, dada una pieza musical, obtener mediante diferentes métodos los elementos sonoros de los que se compone.

Con este problema en mente se ha elegido el aprendizaje automático como método para llevar a cabo la tarea.
Además de implementar un sistema que permite la separación de una obra musical en sus diferentes componentes sonoros, también se comparan distintos métodos para valorar numéricamente el aprendizaje realizado por el sistema dando así una valoración individual por cada método propuesto y una comparativa que permite visualizar cuál de todos tiene un mejor desempeño sobre la tarea propuesta.

El trabajo también aporta una tabla comparativa de los distintos métodos propuestos, un sistema que permite obtener de dos a cuatro elementos presentes en una obra musical de entrada,
 y una interfaz gráfica que proporciona accesibilidad a un usuario promedio ajeno al tema. Esto último, además, se ha tratado de llevar a cabo de forma que el usuario pueda entender de forma interactiva lo que está haciendo al variar parámetros o funciones del modelo, añadiendo explicaciones detalladas de cada campo y de los procesos que se están llevando a cabo internamente en el procesado.
