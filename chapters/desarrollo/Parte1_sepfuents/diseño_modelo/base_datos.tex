Para la base de datos se eligió \textit{MUSDB18}\cite{musdb18}.

Se trata de una relación de 150 pistas musicales de diferentes géneros y sus respectivos elementos musicales aislados en cuatro grupos: batería, bajo, vocales y otros.

En la web de presentación de la base de datos a la cual se puede acceder desde el link proporcionado en la bibliografía se encuentran dos conjuntos diferentes: \textit{MUSDB18} y \textit{MUSDB18-HQ}. Estos dos grupos contienen
la misma relación de canciones y pistas separadas, comprimidas y descomprimidas respectivamente. Ambas versiones contienen las mismas pistas. MUSDB18 estándar emplea un formato comprimido que reduce almacenamiento, mientras que MUSDB18-HQ proporciona audio WAV sin compresión y de ancho de banda completo. Por restricciones de almacenamiento/entrada-salida y coste de procesamiento se utilizó la versión estándar
